**部件设计详情：APPLY-001 - LoanApplicationService**

*   **调用关系**：
    *   **调用者**：`ApplicationController` (前端API入口)
    *   **被调用者**：`UserService` (校验用户), `RabbitMQ` (发送风控任务消息)
*   **输入输出**：

    | 类型 | 参数名 | 数据类型 | 含义 | 约束 |
    | :--- | :--- | :--- | :--- | :--- |
    | **入口参数** | applicationDTO | LoanApplicationDTO | 贷款申请数据传输对象 | 必填 |
    | | | | **(包含: userId, amount, purpose, term)** | |
    | **出口参数** | ApplicationResult | ResultDTO | 申请结果对象 | |
    | | | | **(包含: success, message, applicationId)** | |

*   **处理逻辑**：
    1.  接收前端提交的 `applicationDTO`。
    2.  调用 `UserService` 校验 `userId` 的有效性及实名认证状态。
    3.  **数据校验**：检查 `amount` 是否在允许范围内（如1000-50000元），`term` 是否为有效期限（如3, 6, 12个月）。
    4.  **持久化**：将申请信息存入数据库的 `loan_application` 表，状态为“待风控”。
    5.  **消息发送**：将新生成的 `applicationId` 作为消息体，发送到RabbitMQ的 `risk_task_queue` 队列。
    6.  返回 `ApplicationResult`，其中 `success=true`，`message="申请提交成功"`，`applicationId` 为数据库生成的ID。

*   **技术细节**：
    *   **表示形式**：Java类 (Service层)
    *   **运行环境**：JDK 17, Spring Boot 3.4.10
    *   **性能要求**：单次调用平均响应时间 < 500ms。

**部件设计详情：RISK-001 - CreditScoreCalculator**

*   **调用关系**：
    *   **调用者**：`RiskControlConsumer` (监听RabbitMQ消息)
    *   **被调用者**：`CreditBureauClient`, `OperatorClient`, `AIService`
*   **输入输出**：

    | 类型 | 参数名 | 数据类型 | 含义 | 约束 |
    | :--- | :--- | :--- | :--- | :--- |
    | **入口参数** | applicationId | String | 贷款申请ID | 必填 |
    | **出口参数** | RiskReport | RiskReportDTO | 风控报告对象 | |
    | | | | **(包含: userId, creditScore, operatorScore, finalScore, riskLevel, detail)** | |

*   **处理逻辑**：
    1.  接收 `applicationId`。
    2.  从数据库查询 `loan_application` 表，获取申请人 `userId` 和基础信息。
    3.  **并行调用**：
        *   使用 `CreditBureauClient` 调用征信中心API，获取征信评分（超时3秒）。
        *   使用 `OperatorClient` 调用运营商API，获取消费行为评分（超时3秒）。
    4.  **AI模型评分**：将获取到的结构化数据（征信、运营商）和非结构化数据（如用户授权的社交行为摘要）输入 `AIService`，由AI模型进行综合分析，输出一个AI评分。
    5.  **综合评分**：根据预设权重（如征信40%，运营商30%，AI模型30%），计算出 `finalScore`，并根据分数段确定 `riskLevel`（如A-低风险, B-中风险, C-高风险）。
    6.  生成详细的 `RiskReport` 并存入数据库。
    7.  更新 `loan_application` 表中该申请的状态为“待审核”。

*   **技术细节**：
    *   **表示形式**：Java类 (Service层)
    *   **运行环境**：JDK 17, Spring Boot 3.4.10
    *   **性能要求**：95%的请求在10秒内完成。
