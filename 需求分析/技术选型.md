# 技术选型

## 后端

1. java
    - **跨平台性**：“一次编写，到处运行”特性使其部署灵活
    - **高性能与稳定性**：JVM 经过多年优化，具备优秀的性能表现和内存管理能力，适合构建高并发、长时间运行的后端服务
    - **强大的生态系统**：拥有大量成熟的库、框架和工具（如 Maven、Gradle、JUnit、Log4j 等）
    - **企业级支持**：广泛用于金融、电信、电商等对稳定性要求高的行业

2. Spring(Spring Boot)
    - **依赖注入（IoC）与面向切面（AOP）**：这是Spring的核心。IoC让代码结构更清晰、更易于管理和测试（松耦合）。AOP可以优雅地解决跨领域问题，如日志、事务、安全等，而无需侵入业务代码。
    - **快速开发**：Spring Boot通过自动配置和 Starter 依赖，极大地减少了XML和样板代码的编写。如只需要引入一个spring-boot-starter-web，就自动配置好了Tomcat和一个基础的Web环境
    - **全面的技术集成**：Spring项目为几乎所有主流技术都提供了无缝集成方案，包括但不限于
        - 数据访问：Spring Data JPA (用于ORM)， Spring Data JDBC, MyBatis集成
        - 安全：Spring Security，功能极其强大的安全框架
        - 消息队列：对Kafka， RabbitMQ等的良好支持
        - 云原生：Spring Cloud为微服务架构提供了一整套解决方案
    - **强大的事务管理**：提供了声明式事务管理，用简单的注解（@Transactional）就能管理复杂的事务，非常方便可靠

3. MySQL
    - **开源免费**：MySQL 是最流行的开源关系型数据库之一，成本低
    - **成熟稳定**：经过数十年发展，事务支持（ACID）、主从复制、备份恢复等机制非常成熟
    - **性能良好**：对于大多数 Web 应用（如用户管理、订单系统、内容管理），MySQL 足够高效
    - **生态兼容性好**：与 Java/Spring 集成无缝（通过 JDBC、MyBatis、JPA/Hibernate 等）
    - **云原生支持**：各大云厂商（阿里云、AWS、腾讯云）都提供托管 MySQL 服务

4. Redis
    - **极高读写性能**：基于内存操作，QPS 可达 10w+，适合缓存热点数据（如用户会话、商品信息）
    - **丰富数据结构**：支持 String、Hash、List、Set、ZSet 等，可用于实现排行榜、限流、分布式锁等场景
    - **持久化与高可用**：支持 RDB/AOF 持久化，以及主从复制、哨兵、集群模式，保障数据安全和系统可用性
    - **减轻数据库压力**：将频繁读取的数据缓存到 Redis，显著降低 MySQL 负载
    - **与Spring集成良好**：通过 Spring Data Redis 可轻松操作 Redis
