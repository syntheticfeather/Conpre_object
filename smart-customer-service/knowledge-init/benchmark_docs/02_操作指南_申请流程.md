# 贷款申请全流程操作指南

## 一、申请前准备

### 1.1 确认自身条件

在提交贷款申请前，请确认您满足以下基本条件：
- 年满22周岁，不超过55周岁
- 中国大陆居民，持有有效二代身份证
- 有稳定工作和收入来源（当前单位工作满6个月以上）
- 个人征信报告无当前逾期记录
- 手机号已实名认证且使用超过6个月

### 1.2 准备申请材料

**必备材料**：
- 本人二代身份证原件（正反面拍照）
- 本人实名认证手机号
- 本人名下银行储蓄卡（支持工农中建交及主流股份制银行）

**增信材料（非必需但有助于提升通过率和额度）**：
- 近6个月工资卡银行流水
- 社保/公积金缴纳证明
- 工作证明或在职证明
- 学历学位证书
- 房产证或车辆登记证（作为资产证明）

## 二、APP端申请流程

### 2.1 注册与实名认证

1. 下载安装APP后，使用手机号注册账号
2. 设置登录密码（8-16位，需包含字母和数字）
3. 进入「我的」→「身份认证」→上传身份证正反面照片
4. 系统自动识别身份证信息，请核对无误后确认
5. 按照提示完成人脸识别（确保光线充足、面部无遮挡）
6. 绑定本人名下的银行储蓄卡
7. 设置6位数字交易密码

### 2.2 选择产品并提交申请

1. 在首页浏览可选产品，或根据系统推荐选择
2. 点击「立即申请」进入申请页面
3. 填写借款金额（在授信额度范围内）和期望期限
4. 选择还款方式（等额本息/等额本金/先息后本）
5. 确认贷款用途（需在合规用途范围内选择）
6. 上传补充材料（可选，但建议上传以提高通过率）
7. 仔细阅读借款协议，确认无误后勾选同意
8. 输入交易密码，提交申请

### 2.3 审核阶段

- **系统自动审核**（信用贷款）：通常在30分钟内完成
- **人工复核**（大额贷款）：1-3个工作日
- 审核期间请保持手机畅通，风控人员可能会电话核实信息
- 审核结果会通过APP推送和短信通知

### 2.4 签约与放款

1. 审核通过后，在APP内查看并确认电子借款合同
2. 核对合同关键条款：借款金额、年化利率、还款计划表、违约责任
3. 使用数字证书/电子签名完成签约
4. 签约完成后，资金将在规定时间内打入绑定的银行卡
5. 放款后会收到短信通知和APP推送

## 三、申请被拒后的应对

如果贷款申请被拒绝，建议按以下步骤处理：

1. **查看拒绝原因**：APP内会显示拒绝的具体原因类别
2. **检查征信报告**：前往央行征信中心官网查询个人征信，确认是否有异常
3. **改善信用状况**：结清其他逾期欠款，保持良好还款记录
4. **降低负债率**：提前偿还部分现有债务
5. **完善个人资料**：补充更多收入证明和资产证明
6. **间隔3个月后再申请**：不建议短期内反复提交申请（每次申请都会留下征信查询记录）

## 四、常见问题

### 人脸识别失败怎么办？
- 确保环境光线充足
- 摘掉帽子、墨镜、口罩
- 保持面部正对摄像头
- 如多次失败，可联系客服协助

### 身份证识别不通过？
- 确保证件在有效期内
- 拍照时保证证件平整、无反光
- 四角完整，无遮挡
- 如仍无法识别，可手动输入后由人工审核
