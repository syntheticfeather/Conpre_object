# 风控规则与审核标准说明

## 一、风控体系概述

本平台建立了多层次、全流程的智能风控体系，结合传统征信数据、互联网行为数据和机器学习模型，对每笔贷款申请进行全面的风险评估。风控的最终目标是在控制风险的前提下，为更多合规用户提供便捷的信贷服务。

## 二、核心审核维度

### 2.1 身份核验

- 身份证信息与公安系统实时比对
- 人脸识别活体检测，防止照片/视频攻击
- 手机号实名信息与运营商数据交叉验证
- 银行卡四要素（姓名+身份证+银行卡号+预留手机号）一致性校验

### 2.2 信用评估

**征信报告分析指标**：
- 当前是否有逾期未还的贷款或信用卡
- 过去24个月内逾期次数和严重程度（逾期30天/60天/90天+分别计分）
- 信用卡使用率（已用额度/总额度，超过70%被视为高风险）
- 征信查询次数（近3个月≥6次为高风险信号）
- 信贷历史长度（有3年以上正常信贷记录为加分项）

**平台内部信用分**：
- 历史借款的还款及时率
- APP使用频率和活跃度
- 个人信息完整度
- 邀请人信用状况（社交关系链风控）

### 2.3 还款能力评估

**收入验证**：
- 月收入低于3,000元原则上不通过
- 需验证工资流水或社保公积金缴纳记录
- 自由职业者需提供≥6个月的银行流水
- 现金收入需提供辅助证明（如租赁合同、经营流水）

**负债收入比（DTI）计算**：
- DTI = (现有月度总负债) / (月收入)
- 警戒线：DTI ≤ 55%
- 超过警戒线的申请将被拒绝或大幅降低授信额度
- 现有负债包括：房贷、车贷、其他信用贷、信用卡最低还款额

### 2.4 反欺诈审核

**设备指纹**：
- 检测设备是否被Root/越狱
- 检测是否使用模拟器、改机工具
- 设备关联多个账户视为高风险

**行为分析**：
- 申请填写速度和修改次数（过快或反复修改为异常）
- 地理位置与身份证/银行卡归属地的一致性
- 申请时间（凌晨2-5点申请的欺诈率显著偏高）

**关联网络**：
- 设备、IP、WiFi、通讯录等维度的关联图谱
- 识别团伙欺诈模式

## 三、审核结果说明

### 3.1 通过（全额/部分通过）

- **全额通过**：申请额度全部获批，按申请金额放款
- **部分通过**：系统根据风险评估调降额度（如申请10万获批6万），用户可在APP内确认是否接受

### 3.2 拒绝

拒绝原因会在APP内展示主要类别，具体包括：
- **征信类**：当前逾期、严重逾期记录、征信查询过多
- **收入类**：收入不足、收入证明不充分、负债过高
- **欺诈类**：身份核验失败、设备异常、关联风险
- **政策类**：年龄不符、非目标客群、地区限制

## 四、审核时效

| 产品类型 | 审核方式 | 预计时效 |
|---------|---------|---------|
| 极速贷（≤5万） | 纯系统自动 | 5-30分钟 |
| 优享贷（5-20万） | 系统+人工 | 1-3个工作日 |
| 大额尊享（20-50万） | 全面人工 | 3-7个工作日 |
| 公积金贷 | 系统自动+数据对接 | 1个工作日 |

## 五、被拒后再次申请的建议

1. 被拒后不要立即重复申请，每次申请都会产生征信查询记录
2. 建议间隔至少3个月
3. 针对拒绝原因进行针对性改善
4. 改善后可补充新的收入证明或资产证明再申请
5. 同一时间段内向多家机构申请贷款会触发多头借贷风险预警
