## 3. 上传知识库问答对

网址：/api/knowledge/

请求方式：POST

请求参数说明：

|参数|描述|类型|
|---|---|---|
|question|问题|字符串|
|answer|回答|字符串|
|category|分类|字符串|

请求示例（请求体）：

```json
{
  "question": "测试问题",
  "answer": "测试回答",
  "category": "通用"
}
```
