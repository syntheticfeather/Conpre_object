## 管理员接口

### 增加知识库

**网址** http://localhost:8000/knowledge/

**请求方式** POST

**请求示例（请求体）**  

```json
{
  "question": "提交申请后什么时候能通过？",
  "answer": "提交贷款申请后，通常需要审核1-2天",
  "category": "通用"
}
```

**返回数据示例（响应体）**  

```json
{
  "code": 200,
  "data": {
    "id": "0b813589-c857-4161-89bc-cfa594cf74ac",
    "question": "提交申请后什么时候能通过？",
    "answer": "提交贷款申请后，通常需要审核1-2天",
    "category": "通用",
    "created_at": "2026-04-27 20:32:49",
    "updated_at": "2026-04-27 20:32:49"
  },
  "message": "添加成功"
}
```
