> 时间：2026-06-04
> 基于：Mem0 多信号检索 + Zep 时序感知

## 架构

```
┌── 长期记忆 ──┐          ┌── 短期记忆 ──┐

│ user_memory  │          │ chat_history  │
│              │          │               │

       │                         │
       └──────────┬──────────────┘
                  ▼
            Agent 同时使用两者
```

## 数据流

```
对话前（注入）:
  用户消息 → UserMemoryStore.search(user_id, message)
    → Semantic 层（提炼后的记忆）
    → 得分 > 0.3 → 注入 system prompt
    → 得分 ≤ 0.3 → 补 MongoDB Episode（最近 2 轮原始对话）

对话后（提取）:
  MemoryExtractor.extract_and_save(user_id, message, full_response)
    → LLM 提取偏好/事实/习惯
    → UserMemoryStore.save() → ChromaDB
```

## 存储模型

```json
{
  "document": "用户偏好等额本息还款方式",
  "metadata": {
    "user_id": "4",
    "type": "preference",      // preference / fact / habit / summary
    "key": "repaid_type",
    "importance": 0.8,
    "entities": "等额本息,还款方式",
    "created_at": "2026-06-04T10:00:00",
    "valid_until": "2027-06-04T10:00:00"   // 默认 1 年有效
  }
}
```

## 检索评分公式（Mem0 式多信号）

```
final_score = vector_similarity × 0.50    ← 语义相关性
            + importance × 0.20            ← 提取时的重要性评分
            + time_decay × 0.15            ← e^(-λt)，90天半衰期
            + entity_match × 0.15          ← query 实体命中记忆实体

time_decay = e^(-λ × days)
λ = ln(2) / 90       （90 天半衰期）
```

## 时序感知（Zep 式）

### 冲突检测
写入新记忆时，同 `user_id + key` 的旧记忆自动标为过期：

```
旧: "用户偏好 Python"  [valid_until: null]
新: "用户最近转 Go"    [key: "language_preference"]

→ 旧记忆 valid_until = 当前时间（过期）
→ 新记忆 valid_until = 1 年后
```

### 检索过滤
搜索时自动跳过 `valid_until < now` 的过期记忆。

### 统计接口
```python
UserMemoryStore().stats(user_id)
→ {"total": 12, "active": 9, "expired": 3}
```
