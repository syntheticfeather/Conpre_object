
层与层之间解除耦合：
    控制反转 IOC: 
        将对象的创建和依赖关系的管理从程序代码中分离出来，
        并通过容器（比如 Spring）来管理这些对象。

    依赖注入 DI:
        容器通过配置（比如 XML 或注解）来注入依赖对象，

    Bean 对象:
        容器管理的对象称为 Bean，它是由容器创建、配置和管理的对象。
        bean的名字默认是类名首字母小写。

    注解实现:
        控制反转:
            @component : 标记一个类为 Spring Bean
            @service : 标记一个类为 Service
            @controller : 标记一个类为 Controller 包含在 restcontroller 中
            @repository("指定的bean名字") : 标记一个类为 Repository
            @Mapper : 标记一个类为 MyBatis Mapper

        依赖注入:
            @autowired : 自动注入 Bean
            三种注入方式:
                构造函数注入
                @Autowired
                public UserService(UserDao userDao) {
                    this.userDao = userDao;
                }
                set方法注入
                @Autowired
                public void setUserService(UserService userService) {
                    this.userService = userService;
                }
                字段注入
                @Autowired
                private UserService userService;

    对于有多个实现类的容器注入:
        @Primary : 容器会自动选择该 Bean 的首选实现类
        @Qualifier("自定义的名字") : 容器会根据指定的名字来注入 Bean
                                    要在实现类和注入点都写上
        @resource("指定的bean名字") : 容器会根据名称来注入 Bean，如果没有找到 Bean 则抛出异常
                                     注入点写上注解

    
    Bean扫描:
        注解标注后并不一定就能被放入容器中, 需要通过组件扫描来加载 Bean。
        容器通过扫描指定包下的类，自动发现 Bean 并注册到容器中。        
        @componentScan("指定包名") 写在启动类上
        @springbootApplication : 会自动扫描该注释的同级目录的所有文件

    Bean注册:
        容器会自动注册 Bean，但有时需要手动注册 Bean。
        @bean
            注册类configuration.java中书写
        @import(Configfiguration.class) 
            Application下引入注册类

        或者写一个Selector类，引入多个注册
            @import(Selector.class)

        Selector中
            读取Common.Imports文件，并得到注册类的全限定名
            return string[] {"Configuration1", "Configuration2"};
        
        在 Common.Imports 文件中，不需要写 .class，只需要写类或包的全限定名。
        而使用 @Import 注解时，需要写类的全限定名并加上 .class 后缀。

        对Bean对象进行赋值
            传参即可
            还有很多条件注解
            @ConditionalOnProperty(prefix = "配置文件前缀", name = "属性名", havingValue = "属性值") : 配置文件中存在对应属性，才进行注入
            @ConditionalOnBean(容器中存在指定Bean，才进行注入)
            @ConditionalOnMissingBean(容器中不存在指定Bean，才进行注入)

        关于自动导入配置类
            @SpringBootApplication
                @EnableAutoConfiguration
                    内部 import AutoConfigurationImportSelector.java
                        实现了 SelectorImport
                            读取了META-INF下的.imports文件
                                并将其中的类名转换为全限定名
                                    解析各类注解，并注册到容器中
