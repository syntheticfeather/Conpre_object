## 一、BaseTable 组件

通用表格组件，基于 Ant Design Vue 的 `a-table` 封装，支持分页、排序、筛选、行选择等功能。

### 1.1 属性说明

| 属性名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|--------|------|------|
| `dataSource` | `Array` | `[]` | 否 | 表格数据源 |
| `columns` | `Array` | - | 是 | 列配置数组 |
| `loading` | `Boolean` | `false` | 否 | 加载状态 |
| `currentPage` | `Number` | `1` | 否 | 当前页码 |
| `pageSize` | `Number` | `10` | 否 | 每页条数 |
| `total` | `Number` | `0` | 否 | 数据总条数 |
| `rowKey` | `String` | `'id'` | 否 | 行数据的唯一标识字段名 |
| `showPagination` | `Boolean` | `true` | 否 | 是否显示分页 |
| `showRowSelection` | `Boolean` | `false` | 否 | 是否显示行选择框 |
| `showBatchActions` | `Boolean` | `false` | 否 | 是否显示批量操作区域 |
| `showIndex` | `Boolean` | `false` | 否 | 是否显示序号列 |
| `showAction` | `Boolean` | `false` | 否 | 是否显示操作列 |
| `scroll` | `Object` | `undefined` | 否 | 表格滚动配置 |
| `rowClickable` | `Boolean` | `true` | 否 | 行是否可点击 |
| `minHeight` | `String` | `220px` | 否 | 表格最小高度 |

### 1.2 事件说明

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `page-change` | `(page: Number)` | 页码改变时触发 |
| `edit` | `(record: Object)` | 点击编辑按钮时触发 |
| `delete` | `(record: Object)` | 点击删除按钮时触发 |
| `batch-delete` | `(keys: Array, rows: Array)` | 批量删除时触发 |
| `selection-change` | `(keys: Array, rows: Array)` | 选择项改变时触发 |
| `table-change` | `({ pagination, filters, sorter })` | 表格状态改变时触发 |
| `row-click` | `(record: Object, index: Number)` | 点击行时触发 |

### 1.3 插槽说明

| 插槽名 | 参数 | 说明 |
|--------|------|------|
| `action` | `{ record, index }` | 自定义操作列内容 |
| `batch-actions` | `{ selectedRows, selectedKeys }` | 自定义批量操作按钮 |
| `[column.slotName]` | `{ record, column, index }` | 自定义列内容 |

### 1.4 暴露方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `clearSelection` | - | - | 清除选择项 |
| `setSelection` | `(keys, rows)` | - | 设置选择项 |
| `getSelection` | - | `{ keys, rows }` | 获取当前选择项 |

### 1.5 使用示例

#### 基础用法

```vue
<template>
  <BaseTable
    :data-source="users"
    :columns="columns"
    :loading="loading"
    :current-page="currentPage"
    :total="total"
    @page-change="handlePageChange"
    @row-click="handleRowClick"
  />
</template>

<script setup>
import { ref } from 'vue'
import BaseTable from '@/components/shared/BaseTable.vue'

const users = ref([])
const loading = ref(false)
const currentPage = ref(1)
const total = ref(0)

const columns = [
  { title: '用户名', dataIndex: 'name', key: 'name' },
  { title: '手机号', dataIndex: 'phone', key: 'phone' },
  { title: '状态', dataIndex: 'status', key: 'status' }
]

const handlePageChange = (page) => {
  currentPage.value = page
}

const handleRowClick = (record) => {
  console.log('点击行:', record)
}
</script>
```

#### 带操作列

```vue
<template>
  <BaseTable
    :data-source="products"
    :columns="columns"
    :show-action="true"
    @edit="handleEdit"
    @delete="handleDelete"
  />
</template>

<script setup>
const columns = [
  { title: '产品名称', dataIndex: 'name', key: 'name' },
  { title: '利率', dataIndex: 'rate', key: 'rate' }
]

const handleEdit = (record) => {
  console.log('编辑:', record)
}

const handleDelete = (record) => {
  console.log('删除:', record)
}
</script>
```

#### 带批量操作

```vue
<template>
  <BaseTable
    ref="tableRef"
    :data-source="data"
    :columns="columns"
    :show-row-selection="true"
    :show-batch-actions="true"
    @batch-delete="handleBatchDelete"
  >
    <template #batch-actions="{ selectedKeys }">
      <a-button type="primary" @click="handleExport(selectedKeys)">
        导出选中
      </a-button>
    </template>
  </BaseTable>
</template>

<script setup>
import { ref } from 'vue'

const tableRef = ref()

const handleBatchDelete = (keys, rows) => {
  console.log('批量删除:', keys, rows)
}

const handleExport = (keys) => {
  console.log('导出:', keys)
}
</script>
```

#### 自定义列插槽

```vue
<template>
  <BaseTable :data-source="users" :columns="columns">
    <template #status="{ record }">
      <a-tag :color="record.status === 'ACTIVE' ? 'green' : 'red'">
        {{ record.status === 'ACTIVE' ? '激活' : '禁用' }}
      </a-tag>
    </template>
  </BaseTable>
</template>

<script setup>
const columns = [
  { title: '用户名', dataIndex: 'name', key: 'name' },
  { title: '状态', dataIndex: 'status', key: 'status', slotName: 'status' }
]
</script>
```

## 二、BasePagination 组件

通用分页组件，提供简洁的分页功能。

### 2.1 属性说明

| 属性名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|--------|------|------|
| `currentPage` | `Number` | - | 是 | 当前页码 |
| `total` | `Number` | - | 是 | 数据总条数 |
| `pageSize` | `Number` | `10` | 否 | 每页条数 |

### 2.2 事件说明

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `page-change` | `(page: Number)` | 页码改变时触发 |

### 2.3 使用示例

#### 基础用法

```vue
<template>
  <BasePagination
    :current-page="currentPage"
    :total="total"
    :page-size="pageSize"
    @page-change="handlePageChange"
  />
</template>

<script setup>
import { ref } from 'vue'
import BasePagination from '@/components/shared/BasePagination.vue'

const currentPage = ref(1)
const total = ref(100)
const pageSize = ref(10)

const handlePageChange = (page) => {
  currentPage.value = page
}
</script>
```

#### 与表格配合使用

```vue
<template>
  <div>
    <BaseTable
      :data-source="paginatedData"
      :columns="columns"
      :show-pagination="false"
    />
    <BasePagination
      :current-page="currentPage"
      :total="data.length"
      :page-size="pageSize"
      @page-change="handlePageChange"
    />
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'
import BaseTable from '@/components/shared/BaseTable.vue'
import BasePagination from '@/components/shared/BasePagination.vue'

const data = ref([])
const currentPage = ref(1)
const pageSize = ref(10)

const paginatedData = computed(() => {
  const start = (currentPage.value - 1) * pageSize.value
  return data.value.slice(start, start + pageSize.value)
})

const handlePageChange = (page) => {
  currentPage.value = page
}
</script>
```

## 三、DateRangePicker 组件

日期范围选择器组件，用于选择开始和结束日期。

### 3.1 属性说明

| 属性名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|--------|------|------|
| `startDate` | `String` | `''` | 否 | 开始日期 |
| `endDate` | `String` | `''` | 否 | 结束日期 |
| `format` | `String` | `'YYYY-MM-DD'` | 否 | 日期格式 |
| `disabled` | `Boolean` | `false` | 否 | 是否禁用 |

### 3.2 事件说明

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `update:startDate` | `(date: String)` | 开始日期改变时触发 |
| `update:endDate` | `(date: String)` | 结束日期改变时触发 |
| `change` | `({ startDate, endDate })` | 日期范围改变时触发 |

### 3.3 使用示例

```vue
<template>
  <DateRangePicker
    v-model:start-date="startDate"
    v-model:end-date="endDate"
    @change="handleDateChange"
  />
</template>

<script setup>
import { ref } from 'vue'
import DateRangePicker from '@/components/shared/DateRangePicker.vue'

const startDate = ref('')
const endDate = ref('')

const handleDateChange = ({ startDate, endDate }) => {
  console.log('日期范围:', startDate, endDate)
}
</script>
```

## 四、自定义插槽使用指南

### 4.1 BaseTable 插槽详解

#### 操作列插槽

```vue
<BaseTable :show-action="true">
  <template #action="{ record, index }">
    <a-space>
      <a-button type="link" size="small" @click="handleView(record)">查看</a-button>
      <a-button type="link" size="small" @click="handleEdit(record)">编辑</a-button>
      <a-popconfirm title="确定删除？" @confirm="handleDelete(record)">
        <a-button type="link" size="small" danger>删除</a-button>
      </a-popconfirm>
    </a-space>
  </template>
</BaseTable>
```

#### 自定义数据列插槽

```vue
<template>
  <BaseTable :columns="columns" :data-source="data">
    <template #avatar="{ record }">
      <a-avatar :src="record.avatar" />
    </template>
    
    <template #amount="{ record }">
      <span :style="{ color: record.amount > 10000 ? 'red' : 'green' }">
        ¥{{ record.amount.toLocaleString() }}
      </span>
    </template>
    
    <template #status="{ record }">
      <a-badge 
        :status="record.status === 'APPROVED' ? 'success' : 'processing'" 
        :text="statusText[record.status]" 
      />
    </template>
  </BaseTable>
</template>

<script setup>
const columns = [
  { title: '头像', key: 'avatar', slotName: 'avatar' },
  { title: '金额', dataIndex: 'amount', key: 'amount', slotName: 'amount' },
  { title: '状态', dataIndex: 'status', key: 'status', slotName: 'status' }
]

const statusText = {
  PENDING: '待审核',
  APPROVED: '已通过',
  REJECTED: '已拒绝'
}
</script>
```

#### 批量操作插槽

```vue
<template>
  <BaseTable
    :show-row-selection="true"
    :show-batch-actions="true"
  >
    <template #batch-actions="{ selectedRows, selectedKeys }">
      <a-button type="primary" @click="handleBatchApprove(selectedKeys)">
        批量通过
      </a-button>
      <a-button danger @click="handleBatchReject(selectedKeys)">
        批量拒绝
      </a-button>
      <a-button @click="handleExport(selectedRows)">
        导出数据
      </a-button>
    </template>
  </BaseTable>
</template>
```

### 4.2 插槽最佳实践

1. **命名规范**：插槽名使用 kebab-case，如 `slot-name="user-avatar"`

2. **性能优化**：复杂插槽内容建议抽取为独立组件

```vue
<template>
  <BaseTable :columns="columns">
    <template #status="{ record }">
      <StatusTag :status="record.status" />
    </template>
  </BaseTable>
</template>
```

3. **类型安全**：使用 TypeScript 时，可以为插槽参数定义类型

```typescript
interface SlotProps {
  record: User
  column: Column
  index: number
}
```

4. **组合使用**：多个插槽可以组合使用，实现复杂的表格功能

```vue
<BaseTable
  :columns="columns"
  :show-action="true"
  :show-row-selection="true"
  :show-batch-actions="true"
>
  <template #status="{ record }">
    <StatusTag :status="record.status" />
  </template>
  
  <template #action="{ record }">
    <ActionButtons :record="record" @edit="handleEdit" @delete="handleDelete" />
  </template>
  
  <template #batch-actions="{ selectedKeys }">
    <BatchActions :selected-keys="selectedKeys" />
  </template>
</BaseTable>
```
