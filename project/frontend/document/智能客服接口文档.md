# 智能客服 API 接口文档

## 一、知识库管理接口 (knowledge)

### 1. 获取所有问答对知识项
- **URL**: `/api/knowledge/faq`
- **方法**: GET
- **请求头**: `Authorization: Bearer <token>`
- **请求体**: 无
- **返回体**: 问答对知识项列表

### 2. 获取所有文档分块知识项
- **URL**: `/api/knowledge/documents`
- **方法**: GET
- **请求头**: `Authorization: Bearer <token>`
- **请求体**: 无
- **返回体**: 文档分块知识项列表

### 3. 创建知识库项
- **URL**: `/api/knowledge/`
- **方法**: POST
- **请求头**: `Authorization: Bearer <token>`
- **请求体**:
```json
{
  "question": "string",      // 必填
  "answer": "string",        // 必填
  "category": "string"       // 可选，默认"通用"
}
```
- **返回体**: 创建结果

### 4. 修改知识库项
- **URL**: `/api/knowledge/{item_id}`
- **方法**: PUT
- **请求头**: `Authorization: Bearer <token>`
- **路径参数**: `item_id` (string) - 知识项ID
- **请求体**:
```json
{
  "question": "string",      // 可选
  "answer": "string",        // 可选
  "category": "string"       // 可选
}
```
- **返回体**: 更新结果

### 5. 删除知识库项
- **URL**: `/api/knowledge/{item_id}`
- **方法**: DELETE
- **请求头**: `Authorization: Bearer <token>`
- **路径参数**: `item_id` (string) - 知识项ID
- **请求体**: 无
- **返回体**: 删除结果

### 6. 按文档名称删除整篇文档的所有分块
- **URL**: `/api/knowledge/document`
- **方法**: DELETE
- **请求头**: `Authorization: Bearer <token>`
- **查询参数**: `document_name` (string) - 文档名称（不含扩展名）
- **请求体**: 无
- **返回体**: 删除结果统计

### 7. 上传知识库文件
- **URL**: `/api/knowledge/upload`
- **方法**: POST
- **请求头**: `Authorization: Bearer <token>`
- **请求体**: `multipart/form-data`
  - `file`: 文件（必填）
  - 支持格式：`.json`（问答对格式或文档格式）、`.md`（Markdown文档格式）
- **返回体**: 上传结果

## 二、工具管理接口 (tools)

### 8. 获取所有工具列表
- **URL**: `/api/tools/`
- **方法**: GET
- **请求头**: `Authorization: Bearer <token>`
- **请求体**: 无
- **返回体**: 工具列表

### 9. 按名称搜索工具
- **URL**: `/api/tools/search`
- **方法**: GET
- **请求头**: `Authorization: Bearer <token>`
- **查询参数**: `name` (string) - 工具名称
- **请求体**: 无
- **返回体**: 搜索结果

### 10. 设置工具状态
- **URL**: `/api/tools/{tool_name}`
- **方法**: PUT
- **请求头**: `Authorization: Bearer <token>`
- **路径参数**: `tool_name` (string)
- **查询参数**: 
  - `name` (string) - 必填
  - `version` (string) - 可选，默认"1.0"
- **请求体**: 工具状态信息
- **返回体**: 设置结果
