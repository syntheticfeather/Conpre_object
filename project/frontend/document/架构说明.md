# 前端架构说明

## 一、项目概述

本项目是一个借贷APP管理员控制系统，采用 Vue 3 + Pinia + Vue Router 技术栈，使用 Element Plus 和 Ant Design Vue 作为 UI 组件库。

## 三、各模块职责划分

### 3.1 API 模块 (`src/api/`)

负责与后端 API 的通信，统一管理所有接口请求。

| 文件 | 职责 |
|------|------|
| `auth.js` | 登录、注册、登出等认证接口 |
| `user.js` | 用户列表、黑名单管理接口 |
| `loan.js` | 贷款产品 CRUD 接口 |
| `application.js` | 申请审核相关接口 |

### 3.2 组件模块 (`src/components/`)

#### 3.2.1 布局组件 (`layout/`)

| 组件 | 职责 |
|------|------|
| `NavbarMenu.vue` | 顶部导航栏，包含用户信息、退出登录 |
| `SidebarMenu.vue` | 侧边栏菜单，导航各功能模块 |

#### 3.2.2 通用组件 (`shared/`)

| 组件 | 职责 |
|------|------|
| `BaseTable.vue` | 通用表格组件，支持排序、筛选、分页 |
| `BasePagination.vue` | 通用分页组件 |
| `DateRangePicker.vue` | 日期范围选择器 |

#### 3.2.3 业务组件

| 目录 | 职责 |
|------|------|
| `application-review/` | 申请审核相关组件（待处理、已完成列表） |
| `product/` | 产品表格、产品详情面板 |
| `user/` | 用户表格、黑名单表格、用户详情面板 |

### 3.3 状态管理模块 (`src/stores/`)

采用 Pinia 进行状态管理，各 Store 职责如下：

| Store | 职责 | 主要状态 |
|-------|------|----------|
| `app.js` | 应用全局状态 | loading、请求队列 |
| `auth.js` | 用户认证状态 | token、userInfo、isAuthenticated |
| `user.js` | 用户管理状态 | users、blacklist、userDetail |
| `loan.js` | 贷款产品状态 | products、currentProduct |
| `application.js` | 申请审核状态 | pendingApplications、completedApplications |

### 3.4 视图模块 (`src/views/`)

| 页面 | 路由 | 职责 |
|------|------|------|
| `LoginView.vue` | `/login` | 用户登录页面 |
| `RegisterView.vue` | `/register` | 用户注册页面 |
| `DashboardView.vue` | `/dashboard` | 主控制台，包含侧边栏和内容区 |
| `PendingApplicationView.vue` | `/dashboard/pending-applications` | 待处理申请列表 |
| `CompletedApplicationView.vue` | `/dashboard/completed-applications` | 已完成申请列表 |
| `ProductManageView.vue` | `/dashboard/products` | 产品管理列表 |
| `AddProductView.vue` | `/dashboard/add-product` | 添加产品页面 |
| `UserManageView.vue` | `/dashboard/users` | 用户管理列表 |
| `BlackUserManageView.vue` | `/dashboard/blacklist` | 黑名单管理 |
| `RiskManageView.vue` | `/dashboard/risk` | 风险管理 |

## 五、状态管理流程图

### 5.1 认证流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  LoginView  │────>│  authAPI    │────>│  Backend    │
└─────────────┘     └─────────────┘     └─────────────┘
       │                   │
       │                   ▼
       │           ┌─────────────┐
       └──────────>│  authStore  │
                   │  - token    │
                   │  - userInfo │
                   └─────────────┘
                         │
                         ▼
                   ┌─────────────┐
                   │ localStorage│
                   │ (持久化存储) │
                   └─────────────┘
```

### 5.2 全局 Loading 控制

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   API请求   │────>│  request.js │────>│   appStore  │
└─────────────┘     └─────────────┘     └─────────────┘
                          │                    │
                          │                    ▼
                          │              showLoading()
                          │                    │
                          ▼                    ▼
                    请求拦截器            loadingCount++
                          │                    │
                          ▼                    ▼
                    发送请求              loading = true
                          │
                          ▼
                    响应拦截器
                          │
                          ▼
                    hideLoading()
                          │
                          ▼
                   loadingCount--
                   if (count === 0)
                     loading = false
```

### 5.3 数据流

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   View      │────>│   Store     │────>│    API      │
│  (用户操作)  │     │  (状态管理)  │     │  (接口请求)  │
└─────────────┘     └─────────────┘     └─────────────┘
       ▲                   │                   │
       │                   ▼                   ▼
       │             ┌─────────────┐     ┌─────────────┐
       └─────────────│   State     │<────│  Response   │
                     │  (响应式数据) │     │  (响应数据)  │
                     └─────────────┘     └─────────────┘
```

## 七、命名规范

### 7.1 文件命名

- **Vue 组件**：PascalCase，如 `UserTable.vue`
- **JS 文件**：camelCase，如 `userStore.js`
- **CSS 文件**：kebab-case，如 `base-table.css`

### 7.2 组件命名

- **组件定义**：PascalCase
- **模板中使用**：PascalCase

### 7.3 Store 命名规范

- **Store 文件**：与业务模块同名，如 `user.js`
- **Store ID**：与文件名一致，如 `defineStore('user', ...)`
- **Action 命名**：
  - 异步获取数据：`fetch + 实体名`，如 `fetchUsers`
  - 设置数据：`set + 属性名`，如 `setUsers`
  - 清除数据：`clear + 属性名`，如 `clearUserDetail`
  - 重置状态：`resetState`

### 7.4 API 命名规范

- **获取列表**：`get + 实体复数`，如 `getUsers`
- **获取详情**：`get + 实体 + Detail`，如 `getUserDetail`
- **创建**：`add + 实体`，如 `addProduct`
- **更新**：`update + 实体`，如 `updateProduct`
- **删除**：`delete + 实体`，如 `deleteProduct`
