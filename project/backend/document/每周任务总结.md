# 每周任务总结

## 第一周（2026-03-09至2026-03-15）

### 一、bug修复

1. 用户注册时手机号时可重复

   - 问题：`userRegister`函数中未检查手机号是否已存在
   - 修复：用户注册时，先查询数据库，检查手机号是否已存在，若已存在则返回错误信息。

2. 查询认证材料时返回的存储路径错误

   - 问题：数据库存储的图片路径可以直接返回给前端，再用`buildPublicUrl`函数构建完整路径，会导致路径有重复部分，如/uploads/work/employment/uploads/work/employment/employment_10_20260310_ipmkqw.png
   - 修复：使用`buildPublicUrl`函数前，先检查路径是否完整，若不则在路径前添加基础路径。

3. 用户提交认证材料后，查看认证信息返回`creditScore`为空

   - 问题：`submitAllAuth`函数中，保存认证材料后没有调用`calScore`函数即使计算信誉分并存储
   - 修复：在`submitAllAuth`函数中，调用`calScore`函数计算信誉分并存储到数据库中。

### 二、新增功能

1. 为管理员添加认证材料查询接口

   - 可分别根据`workCertId`,`triCertId`,`immovableCertId`查询用户认证材料。

2. 配置Swagger文档，生成接口文档，可通过`http://localhost:8080/doc.html`在浏览器查看可视化接口说明。

   - [openAPI文档](default_OpenAPI.json)。

3. 限制用户输入的申请金额大小

   - `apply`函数中，添加申请金额的验证逻辑，确保申请金额在产品最小额度和最大额度之间。

4. 完成Service层的单元测试
