# 综设2每周计划

## 第二周（2026-03-09至2026-03-15）

1. 优化AI审批逻辑 ：将 AIApproveServiceImpl.java 中的随机审批改为基于规则的初步风控，即根据黑名单，信誉分，最高额度，认证材料，贷款期限，利率，申请金额，综合计算AI通过率。

    黑名单规则

    - 用户在黑名单，直接拒绝

    信誉分规则

    - 信誉分越高，设置通过率越高

    申请金额规则

    - 申请金额 ≤ 用户最高额度 × 0.5：通过率 +20%
    - 申请金额 ≤ 用户最高额度 × 0.8：通过率 +10%

    认证材料规则

    - 完整认证（工作+第三方+不动产）：通过率 +30%
    - 部分认证（任意2项）：通过率 +15%
    - 单项认证：通过率 +5%
    - 无认证：通过率 -20%

    贷款期限规则

    - 期限 ≤ 12个月：通过率 +10%
    - 期限 13-36个月：通过率 +5%
    - 期限 > 36个月：通过率 -10%

    利率规则

    - 利率 ≤ 5%：通过率 +5%
    - 利率 5%-10%：通过率 -5%
    - 利率 > 10%：通过率 -10%

2. 代码规范：统一命名规范，移除重复代码，为业务逻辑层的方法添加必要的注释。

3. 实现认证材料上传、修改、查看功能
