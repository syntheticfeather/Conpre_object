## 项目一：个人贷款管理系统（Personal Loan System）

### 1. 项目概述

**项目背景**：面向金融机构的贷款业务全栈管理平台，提供贷款产品配置、在线申请、人工审批、还款管理、风险控制、实时通知等核心功能，支持管理后台与数据大屏可视化展示。

**项目架构**：
```
前端 (Vue 3)  ───  HTTPS + JWT  ───  后端 (Spring Boot)
                                           │
                                    ┌──────┴──────┐
                                    │  Redis      │
                                    │  RabbitMQ   │
                                    │  MySQL      │
                                    │  SSE        │
                                    └─────────────┘
```

**技术栈**：

| 层级 | 技术 |
|------|------|
| 核心语言 | Java 17 |
| 基础框架 | Spring Boot 3.4 |
| ORM | MyBatis 3.0 + Hibernate |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis（Redisson） |
| 消息队列 | RabbitMQ（Spring AMQP） |
| 安全认证 | Spring Security + JWT |
| 文档 | SpringDoc OpenAPI + Knife4j |

### 3. 技术亮点

#### 3.1 Redis 三层缓存保护机制

| 层级 | 组件 | 作用 |
|------|------|------|
| 第一层 | 布隆过滤器（BloomFilter） | 过滤不存在的数据请求，防止缓存穿透 |
| 第二层 | Redis 缓存 | 热点数据快速访问 |
| 第三层 | Redisson 分布式锁 | 保护缓存重建过程，防止缓存击穿 |

**缓存查询模板**：
1. 布隆过滤器判断 key 是否可能存在
2. 缓存命中则直接返回
3. 未命中则加分布式锁（tryLock 3秒等待，10秒自动释放）
4. 双检确认（Double Check）后查数据库并回填缓存

**防雪崩设计**：使用随机过期时间（基础1小时 + 0~300秒随机偏移），避免大量 key 同时过期。

#### 3.2 RabbitMQ Outbox Pattern

```
业务操作 + 写 Outbox 表（同一事务）
           ↓
   OutboxMessagePoller（定时轮询，每5秒）
           ↓
   投递到 RabbitMQ + 状态机流转
           ↓
   SENT（成功）/ FAILED（失败）
```

**消息状态机**：`PENDING → SENDING → SENT / FAILED`

**补偿机制**：每60秒回滚超时消息（SENDING 状态超过120秒 → PENDING），确保消息不丢失。

## 项目二：智能客服系统（AI Customer Service）

### 1. 项目概述

**项目背景**：基于大语言模型的智能客服系统，通过 Agent 架构实现多工具调用，支持贷款业务查询、还款计算、知识库问答等功能，提供 SSE 流式响应。

**项目架构**：
```
前端 ─────────────── SSE 流式响应 ─────────────── 后端 (FastAPI)
                                                       │
                                    ┌──────────────────┼──────────────────┐
                                    │                  │                  │
                               LangChain Agent    Vector Store      Java API
                               (DeepSeek LLM)    (ChromaDB)      (个人贷款系统)
```

**技术栈**：

| 层级 | 技术 |
|------|------|
| 核心语言 | Python 3.10+ |
| Web 框架 | FastAPI + Uvicorn |
| AI 框架 | LangChain (Agent Executor) |
| LLM | DeepSeek Chat (API) |
| 向量数据库 | ChromaDB |
| 实时通信 | SSE (Server-Sent Events) |
| 认证 | JWT Bearer Token |

---

### 2. 核心功能模块

| 模块 | 功能说明 |
|------|----------|
| **Chat Agent** | 基于 LangChain Agent 的对话处理，支持多工具调用 |
| **Tool Manager** | 工具注册与管理，支持动态启用/禁用工具 |
| **Backend Tools** | 调用个人贷款系统 Java API，查询申请状态 |
| **Repayment Calculator** | 还款计划计算（等额本息/等额本金/先息后本/一次性还本付息） |
| **Knowledge Base** | 知识库管理，基于向量相似度检索 |
| **SSE Streaming** | 流式响应，实时推送工具调用状态 |

---

### 3. 技术亮点

#### 3.1 LangChain Agent 架构

```
用户输入 → ChatAgent → create_tool_calling_agent
                              │
                    ┌─────────┼─────────┐
                    │         │         │
               Tool 1    Tool 2    Tool 3
           (查询申请) (还款计算) (知识库)
```

**事件流处理**：
- `on_tool_start`：工具调用开始，返回工具名和参数
- `on_tool_end`：工具执行结束，返回执行结果
- `on_chat_model_stream`：LLM 输出流式内容
- `on_chain_end`：对话结束

#### 3.2 工具系统设计

**ToolManager 模式**：
- 统一注册机制，支持动态启用/禁用
- 工具描述自动注入提示词
- 异步工具执行支持

**已实现工具**：
| 工具名 | 功能 | 调用外部服务 |
|--------|------|--------------|
| `query_application_status` | 查询贷款申请状态 | 个人贷款系统 Java API |
| `calculate_repayment` | 计算还款计划 | 本地计算 |

#### 3.3 向量知识库

**ChromaDB 持久化存储**：
```python
combined_text = f"问题: {item.question}\n答案: {item.answer}"
collection.add(
    documents=[combined_text],
    metadatas=[{"question": ..., "answer": ..., "category": ...}],
    ids=[item.id]
)
```

**检索流程**：用户问题 → 向量相似度搜索 → 返回 top_k 条知识

#### 3.4 SSE 流式响应

**事件类型**：
| 事件 | 说明 |
|------|------|
| `session_init` | 初始化会话，返回 session_id |
| `tool_call` | 工具调用开始 |
| `tool_result` | 工具执行结果 |
| `message` | LLM 输出片段 |
| `error` | 错误信息 |
| `done` | 对话结束 |
