### 1. 多数据源融合的互联网个人贷款及全流程风控系统 | Java后端核心开发

**项目介绍**：面向金融机构的贷款业务管理平台，提供贷款产品配置、在线申请、人工审批、还款管理等核心功能，支持管理后台与数据可视化展示。

**核心职责**：
- 设计并实现贷款业务核心模块（产品管理、申请审批、订单还款、通知系统）
- 设计 user、loan_product、loan_option、loan_application、order 等 13 张表，采用 Product-Option 分离策略：LoanProduct 表存储产品基础信息（额度范围、期数范围、步长），LoanOption 表存储利率方案，通过 minTerm + termStep 自动生成可选期数列表，支持等额本息、等额本金、先息后本、一次性还本付息四种还款方式
- 基于 RabbitMQ Outbox Pattern 实现事务性消息：业务操作与消息写入同一事务，定时轮询 + 状态机流转（PENDING → SENDING → SENT）保证消息可靠投递，配合 Publisher Confirm/Returns 端到端确认
- 构建 Redis 三层缓存保护机制：布隆过滤器（防穿透）+ Redis 缓存（防击穿）+ Redisson 分布式锁（保护缓存重建），通过随机过期时间规避雪崩
- 设计 RESTful API 30+，统一 ApiResult 响应结构，集成 SpringDoc 自动生成 Swagger 文档

**项目介绍**：为个人贷款系统开发的增强功能模块，通过 LangChain Agent 搭配 RAG 知识库检索，实现用户端与管理员端通用的智能客服系统。用户可通过自然语言查询贷款申请状态、还款计划等业务信息，管理员可在管理端可视化配置 RAG 知识库内容、调整系统参数，实现零代码更新智能问答能力。

**核心职责**：

- 实现 ToolManager 工具管理系统，支持动态注册/禁用工具，工具描述自动注入提示词
- 集成 ChromaDB 向量数据库，实现知识库持久化存储与语义检索，支持动态更新与多租户隔离

### 3. 多模态AI互动式教学智能体 | 独立完成系统设计与后端实现

**项目介绍**：AI 应用实践项目，打通从 RAG 知识库检索到 LLM 多模态生成的全链路。面向高校教师提供 AI 课件生成服务，用户输入课程主题即可自动生成 PPT、Word 教案、知识图谱、互动游戏等多种形态的教学内容，探索 AI 在教育领域的落地应用。

**核心职责**：
- 设计以 `course_json` 为顶层数据源的统一生成架构，课程大纲同时驱动 PPT / Word教案 / 知识图谱 / 互动游戏四条输出链路，保证多模态内容一致性
- 实现多种类文件上传与解析功能，支持 PDF、Word、PPT、图片、视频等格式，对复杂文档使用 LlamaParse MCP 进行高精度转换
- 构建完整的 RAG Pipeline：文档解析 → 文本分割 → 向量嵌入 → ChromaDB 持久化 → 语义检索 → 上下文注入 LLM → 生成内容
