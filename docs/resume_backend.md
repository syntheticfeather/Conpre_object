## 项目经历

### 多数据源融合的互联网个人贷款及全流程风控系统 | 后端核心开发

**项目介绍**：面向金融机构的贷款业务管理平台，提供贷款产品配置、在线申请、人工审批、还款管理等核心功能，支持管理后台与数据可视化展示。

**技术栈**：Java 17 / Spring Boot 3.4 / MySQL 8.0 / Redis / RabbitMQ / JWT

**核心职责**：
- 设计并实现贷款业务核心模块（产品管理、申请审批、订单还款、通知系统）
- 设计 user、loan_product、loan_option、loan_application、order 等 13 张表，采用 Product-Option 分离策略：LoanProduct 表存储产品基础信息（额度范围、期数范围、步长），LoanOption 表存储利率方案，通过 minTerm + termStep 自动生成可选期数列表，支持等额本息、等额本金、先息后本、一次性还本付息四种还款方式
- 基于 RabbitMQ Outbox Pattern 实现事务性消息：业务操作与消息写入同一事务，定时轮询 + 状态机流转（PENDING → SENDING → SENT）保证消息可靠投递，配合 Publisher Confirm/Returns 端到端确认
- 构建 Redis 三层缓存保护机制：布隆过滤器（防穿透）+ Redis 缓存（防击穿）+ Redisson 分布式锁（保护缓存重建），通过随机过期时间规避雪崩
- 应用设计模式：工厂模式封装 Outbox 消息创建策略，策略模式实现差异化还款计算逻辑
