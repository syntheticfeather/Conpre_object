## 项目经历

### 多模态AI互动式教学智能体 | 独立完成系统设计与后端实现

**项目介绍**：AI 应用实践项目，打通从 RAG 知识库检索到 LLM 多模态生成的全链路。面向高校教师提供 AI 课件生成服务，用户输入课程主题即可自动生成 PPT、Word 教案、知识图谱、互动游戏等多种形态的教学内容，探索 AI 在教育领域的落地应用。

**技术栈**：Python 3.10 / FastAPI / SQLite / ChromaDB / LangChain / OpenAI GPT / 通义千问

**核心职责**：
- 设计以 `course_json` 为顶层数据源的统一生成架构，课程大纲同时驱动 PPT / Word教案 / 知识图谱 / 互动游戏四条输出链路，保证多模态内容一致性
- 实现多种类文件上传与解析功能，支持 PDF、Word、PPT、图片、视频等格式，对复杂文档使用 LlamaParse MCP 进行高精度转换
- 构建完整的 RAG Pipeline：文档解析 → 文本分割 → 向量嵌入 → ChromaDB 持久化 → 语义检索 → 上下文注入 LLM → 生成内容
- 实现多模型双轨支持：LLM（通义千问优先 + GPT-4 回退）和 Embedding（DashScope 优先 + OpenAI 回退），Chroma 分片持久化支持多租户知识库隔离

### 智能客服系统 | AI应用开发

**项目介绍**：为个人贷款系统开发的增强功能模块，通过 LangChain Agent 搭配 RAG 知识库检索，实现用户端与管理员端通用的智能客服系统。用户可通过自然语言查询贷款申请状态、还款计划等业务信息，管理员可在管理端可视化配置 RAG 知识库内容、调整系统参数，实现零代码更新智能问答能力。

**技术栈**：Python 3.10 / FastAPI / LangChain / ChromaDB / SSE

**核心职责**：
- 基于 LangChain `create_tool_calling_agent` 架构实现多工具调用 Agent，支持贷款申请查询、还款计算
- 设计 SSE 流式响应机制，通过 `astream_events` 实时推送工具调用状态（tool_call / tool_result）和 LLM 输出，优化交互体验
- 实现 ToolManager 工具管理系统，支持动态注册/禁用工具，工具描述自动注入提示词
- 集成 ChromaDB 向量数据库，实现知识库持久化存储与语义检索，支持动态更新与多租户隔离
- 通过 httpx 异步调用个人贷款系统 Java API，实现跨系统业务查询能力
