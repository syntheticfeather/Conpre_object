
    需要新增赋予管理员权限的功能。放在users/,接口名字zff取。

可视化界面之后再完善

---

#### 前端，因路由需要

- 将js文件，html文件中，有关href，window.location.href等跳转方法，改为绝对路径。

    ```html
    <a href="/login">登录</a>
    
    window.location.href = "/login";
    ```
    
    [参考WebConfig.java](project/backend/personal-loan/src/main/java/com/example/personal_loan/config/WebConfig.java)
    
    ```java
        @Override
        public void addViewControllers(ViewControllerRegistry registry) {
            registry.addViewController("/login").setViewName("login");
            registry.addViewController("/registration").setViewName("registration");
            registry.addViewController("/").setViewName("login");
            registry.addViewController("/index").setViewName("index");
        }
    ```
    
    改写规则如下：
    
    `addViewController("/index")` -->  `window.location.href = "/index"`    `href="/login"`

    命名就以**html的名**为准，但是  是前加`/`，而非后加`.html`。

    总之因为我们要做路由了，不是直接文件跳转了

    **目前的html**我已修改，之后的跳转均以这个格式为准

---

- web端只允许管理员进行登录，如果登录信息返回后，发现登录者身份不是管理员。让其进入用户的首页，而不是现在的index页面。

    所以需对登录相应逻辑进行调整
